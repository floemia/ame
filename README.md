<div align="center">
  <h1>Ame</h1>
</div>

ame is a discord bot with osu!droid commands! this is a work in progress and adapted for my personal use. self hosting is ok!

## install

```bash
git clone https://github.com/floemia/ame.git
cd ./ame
npm i

# create your .env and config.json files, then

npm run build && npm run start
```

## structures

### .env

```bash
OSU_API_TOKEN=asdjaldjadadakld      # your osu! api v1 token!
TOKEN=faklfsfjkljfkalslfjafklj      # your bot's token!
CLIENT_ID=adjsaduc9oh2li22sddk      # your bot's client id!
```
